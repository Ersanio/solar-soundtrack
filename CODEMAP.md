# Code map

Every source file under `packages/*/src`, `web/src` and `scripts`, with the first sentence of its
doc comment. Generated by `npm run codemap`; `npm run check` fails when it is stale. Do not edit by
hand — change the comment and regenerate.

A size is a floor: `(1500+ lines)` is a file of 1500 to 1999. A file of 1000 lines or more carries
an outline of what it declares, each name with its line as of the last regeneration; grep for the
name if the line has drifted. **Rules** names the `.claude/rules/` files whose `paths:` cover
something in the directory, which load by themselves when such a file is opened.

## packages/core/src

- `hardcoded-tables.ts` — Constant tables lifted from AddmusicK's `Music.cpp` and `main.asm`.

- `theme-presets.ts` — The themes the picker offers by name.
- `theme-tokens.ts` (300+ lines) — The colours the porter may change, and how the picker groups them.

## web/src/app/update-banner

- `update-banner.ts` — The banner offering a reload once the service worker has a new version of the app ready.

## web/src/app/util

**Rules:** `roll-view.md`, `ui-and-theme.md`

- `channel-palette.ts` — The eight music channels' colours, as Tailwind class names.
- `format.ts` — Formatting helpers shared by the editor's panels.
- `hex.pipe.ts` — Hex formatting for templates.
- `idb.ts` — A minimal key/value store over IndexedDB, for the sample library.
- `math.ts` — `value`, held inside `[min, max]`.
- `on-change.ts` — Runs `handler` when `source` changes value, and never on the value it starts at.
- `storage.ts` — `localStorage`, for code that would rather carry on without it.
